# Абитуриенту ТюмГУ

Сайт для абитуриентов Тюменского государственного университета и иностранных студентов:
документы и регистрация, медосмотр, общежития, цены 2025 года и встроенный помощник,
который отвечает на вопросы и открывает нужные разделы.

Вся информация собрана из памяток в файле `abitura.md`.

## Страницы

| Страница | Описание |
| --- | --- |
| `index.html` | Главная — обзор разделов и частые вопросы |
| `foreign.html` | «Иностранцам»: документы, регистрация, медицина, общежитие и цены (один маршрут «Путь абитуриента») |
| `student.html` | Студентам: пакет первокурсника, Модеус/ЕЛК, отзывы о предметах, чаты институтов, официальные ссылки |
| `about.html` | О нас: авторы, помощники (студенты старших курсов) и кто может помочь |

Навигация: **Главная · Иностранцам · Студентам · О нас**.

## Запуск

```bash
npm install      # установить зависимости
npm run dev      # dev-сервер (http://localhost:5173)
npm run build    # сборка в папку dist/
npm run preview  # предпросмотр готовой сборки
```

## Как добавить страницу

1. Создайте файл в стиле существующих (копия, например, `foreign.html`).
2. Добавьте его в список `pages` в `vite.config.js`.
3. Обновите меню в шапке и футоре всех страниц.

## Как добавить знания помощнику

Ответы помощника хранятся в `js/assistant.js` — в массиве `KB`.
Добавьте новую запись `{ keys: [...], answer: "...", link: {...} }`.
Ключевые слова — в нижнем регистре, без «ё» (используйте «е»).

## Как изменить авторов на странице «О нас»

Займите карточки в `<section class="team">` на странице `about.html` —
сейчас там заготовки, подставьте имена, факультеты и контакты.

## Деплой на GitHub Pages

Проект настроен под GitHub Pages (относительные пути в сборке —
работает и в подпапке, и с собственным доменом).

Автодеплой: workflow `.github/workflows/deploy.yml` собирает сайт и публикует
при пуше в ветку `main`. В репозитории нужно включить GitHub Pages
(Settings → Pages → Source: **GitHub Actions**).

Сайт будет доступен по адресу вида `https://<user>.github.io/<repo>/`.

