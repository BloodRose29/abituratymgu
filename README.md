# Абитуриенту ТюмГУ

Сайт для абитуриентов Тюменского государственного университета и иностранных студентов:
документы и регистрация, медосмотр, общежития, цены 2025 года и встроенный помощник,
который отвечает на вопросы и открывает нужные разделы.

Собран на современном стеке — **React 19 + TypeScript + Vite 6** (SPA). Весь контент
хранится в данных (`src/content/*`), а HTML — минимальная оболочка: страницы в исходниках
построения не содержат текста, всё отрисовывается на клиенте.

## Страницы (роуты, Hash-роутер)

| Роут | Страница |
| --- | --- |
| `/#/` | Главная — обзор разделов, «Путь абитуриента», частые вопросы |
| `/#/foreign` | «Иностранцам»: документы и регистрация, медицина, цены (вкладки) |
| `/#/student` | Студентам: пакет первокурсника, мед. справки 086/075у, Модеус/ЕЛК, чаты институтов |
| `/#/dorm` | Общежитие: корпуса, что взять, правила, заселение |
| `/#/about` | О нас: авторы, помощники, кто может помочь |

Дополнительно любой раздел можно открыть по якорю: `/#/foreign/medosmotr`,
`/#/student/med-spravki`, `/#/dorm/zaselenie` и т.п.

## Запуск

```bash
npm install      # установить зависимости
npm run dev      # dev-сервер (http://localhost:5173)
npm run build    # сборка в dist/ (tsc --noEmit + vite build)
npm run preview  # предпросмотр готовой сборки
```

## Как добавить/изменить контент

Контент не пишется в JSX — только в `src/content/*.ts`. Несколько типов блоков:

```ts
{ t: 'h2', text: 'Заголовок', id: 'razdel' }   // заголовки
{ t: 'p', text: 'Текст с **жирным** и [ссылкой](/foreign/medosmotr)' }
{ t: 'ul' | 'ol' | 'steps', items: ['…', '…'] }
{ t: 'table', head: ['A','B'], rows: [['x','y'], [null,'z']] }  // null = продолжение ячейки
{ t: 'tip' | 'warn' | 'danger', text: '…' }
{ t: 'links', items: [{ title, sub, url }] }     // официальные ссылки
{ t: 'tggrid', items: [{ name, sub, url }] }     // чаты в Telegram
{ t: 'team', cards: [{ avatar, name, role, tg }] } // команда/помощники
```

В тексте работает мини-разметка: `**жирный**`, `[текст](путь)` — пути `/…` ведут
по роутеру, `#якорь` скроллит к блоку на странице, внешние URL открываются в новой вкладке.

## Помощник

Ответы помощника — в `src/content/assistantKB.ts` (массив `KB`): записи
`{ keys: [...], answer: "...", link: { to, label } }`. Ключи — в нижнем регистре, без «ё».
Ссылка в ответе ведёт на роут сайта (или внешний URL). Чипы-подсказки — массив `CHIPS`.

## Деплой на GitHub Pages

`base: './'` в `vite.config.ts` — сборка работает и в подпапке, и с доменом.
Маршрутизация — HashRouter, поэтому редиректы не нужны (адреса вида `/#/foreign`).

Автодеплой: `.github/workflows/deploy.yml` (npm ci → npm run build → upload dist)
срабатывает при пуше в ветку `main`. Репозиторий: Settings → Pages → Source **GitHub Actions**.

Сайт будет доступен по адресу вида `https://<user>.github.io/<repo>/`.
